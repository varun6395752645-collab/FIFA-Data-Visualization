# FIFA Data Visualization Using Python

## Project Overview
This project explores FIFA 2018 player data using Python and data visualization techniques. It analyzes player overall ratings, preferred foot, weight distribution, and club-level rating comparisons.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis
- **Data Exploration:** Examining dataset information, columns, and descriptive statistics.
- **Histogram:** Visualizing the distribution of FIFA player overall ratings.
- **Pie Chart:** Comparing left-footed and right-footed players.
- **Weight Distribution:** Analyzing players across different weight categories.
- **Box Plot:** Comparing overall ratings of FC Barcelona, Real Madrid, and New England Revolution.

## Skills Demonstrated
- Data loading and exploration
- Data cleaning and transformation
- Filtering data using Pandas
- Statistical summaries
- Data visualization
- Comparative analysis

## How to Run
1. Clone or download this repository.
2. Install the required libraries using `pip install pandas numpy matplotlib`.
3. Place the FIFA dataset in the project folder.
4. Open the notebook in Jupyter Notebook.
5. Run the cells in order.

## Dataset
The project uses FIFA 2018 player data. The dataset file must be provided separately unless included in this repository.
